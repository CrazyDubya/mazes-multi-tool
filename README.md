# Mazes - Multi-Tool Python Project

A comprehensive Python project combining maze generation, AI tools, data science, and various utilities.

## Features

### Maze Generation
- Multiple maze generation algorithms (Recursive Backtracking, Kruskal's, Prim's, Eller's, Recursive Division)
- Maze visualization and export
- Maze completion analysis

### AI & Machine Learning
- LLM integration and synthetic data generation
- Multi-branch reasoning tools
- Conversation and document analysis
- GPT search engine

### Data Science
- Jupyter notebooks for data analysis
- Feature building and model training
- Data visualization tools

### Screen Recording
- Cross-platform screen recording utilities
- FFmpeg integration
- Customizable recording settings

### CAD Tools
- 3D modeling and CAD functionality
- PythonOCC integration

### Board Game Generator
- Automated board game creation
- Configurable game mechanics

## Project Structure
- `data/` - Data files and datasets
- `notebooks/` - Jupyter notebooks for analysis
- `synthetic/` - AI-generated content and tools
- `record/` - Screen recording utilities
- `cad/` - CAD and 3D modeling tools
- `board_game_generator/` - Game generation tools
- `segment-anything-2/` - Meta's SAM2 integration
- `gpt-search-engine/` - GPT-powered search

## Setup
1. Create virtual environment: `python -m venv .venv`
2. Activate: `source .venv/bin/activate`
3. Install dependencies: `pip install -r requirements.txt`

## Usage
Each component can be run independently. Check individual directories for specific instructions.

## Note
Generated images, logs, and model files are gitignored to keep the repository clean.
